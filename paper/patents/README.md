## Labeling rule

- **Implemented**: present in current repo code path
- **Evidenced**: backed by packaged results or completed reports
- **Conceptual**: design idea not yet promoted into the canonical paper
- **Patent candidate**: novelty-oriented idea tracked here
- **Blocked / open problem**: not runnable or not defined enough

Patent notes must explicitly record:

- candidate title
- one-sentence inventive idea
- problem solved
- implementation status
- evidence status
- prior-art adjacency
- disclosure risk if promoted into the paper

## Promotion policy

- Patent statements must remain implementation-grounded and traceable to code evidence.
- Claims must not exceed status in `paper/sections/10-concept-implementation-audit.md`.
- Final legal packages should include claim chart, prior-art grid, and proof artifacts.
