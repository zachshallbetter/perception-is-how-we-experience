Those examples are useful for future design work, but they are not current paper evidence.

## Authority Boundary

The canonical paper is limited to:

- replay-centric continual-learning evidence
- the completed synthetic sensor-routing ladder
- bootstrap real-data evidence
- pending canonical integrated real-data evidence

Domain examples should only appear in the canonical paper as brief future-use framing. They must not be used as current empirical support unless they are both:

1. **Implemented** in the current repo code path, and
2. **Evidenced** by packaged results or completed reports

## Promotion Rule

If a future domain example needs to enter the canonical paper, the required order is:

1. Add or update the concept note in `/reference/future-concepts/`
2. Implement the corresponding code path
3. Run the bounded experiment or sequence
4. Package the results successfully
5. Promote only the artifact-backed conclusion into the canonical paper
