# Supplementary Paper 3: Applications in Robotics, Medical, and Smart Homes

## Scope

This directory captures application-domain evaluation templates and research planning artifacts.
It is not the canonical source for main-paper empirical claims.

Canonical authority remains:
- `paper/sections/05-experiments.md`
- `paper/sections/06-results.md`
- `paper/sections/00-implementation-status-matrix.md`

## Status

- Domain materials are exploratory and intended for future dedicated studies.
- Any numeric outcomes in this directory are non-canonical unless promoted to the main sections.

## Directory Intent

- `robotics/`: real-time multimodal control evaluation template.
- `medical/`: risk-sensitive multimodal diagnostics evaluation template.
- `smart-home/`: concurrent activity and edge deployment evaluation template.
